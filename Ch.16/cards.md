### Front
2. 细胞连接有哪几种类型，各有什么功能？

### Back
表 16-2 细胞连接类型及其功能

| 细胞连接类型 | 结构特点 | 功能 |
| :--- | :--- | :--- |
| 封闭连接（紧密连接） | 一般存在于脊椎动物上皮细胞之间；成串的跨膜蛋白构成网络状蛋白质焊接线，又称嵴线 | 形成渗透屏障，防止溶质渗漏；形成膜蛋白和膜脂侧向扩散的屏障，维持上皮细胞极性 |
| 锚定连接<br>与中间丝相连<br>桥粒 | 细胞与细胞之间两侧对称的纽扣式连接；胞内锚蛋白形成盘状致密斑，胞内与中间丝相连，胞外与跨膜粘连蛋白相连 | 通过桥粒连接，使整个上皮层的中间丝形成一个完整的网络，增加了细胞抵抗外界压力与张力的能力 |
| 锚定连接<br>与中间丝相连<br>半桥粒 | 细胞与细胞外基质的连接方式，角蛋白纤维通过膜上的整联蛋白与细胞外基质的层粘连蛋白相连 | 将上皮细胞粘着在基膜上 |
| 锚定连接<br>与肌动蛋白纤维相连<br>黏着带 | 位于上皮细胞紧密连接的下方，相邻细胞形成连续的带状结构；胞质侧与微丝束相连，胞外侧靠钙黏蛋白形成胞间横桥将相邻细胞连接，钙黏蛋白与细胞骨架之间靠其他连接蛋白联系在一起 | 在动物胚胎发育形态建成过程中，促使上皮细胞层弯曲形成神经管等结构 |
| 锚定连接<br>与肌动蛋白纤维相连<br>黏着斑 | 细胞与细胞外基质之间的连接方式，参与连接的骨架为肌动蛋白纤维，跨膜黏附性蛋白是整联蛋白 | 体外培养的成纤维细胞通过黏着斑附着在培养皿基质上，有助于维持细胞在运动过程中的张力及细胞生长的信号传递 |
| 通讯连接<br>间隙连接 | 连接蛋白六聚体构成连接子，相邻细胞连接子对接，形成直径约为 1.5nm 的通道，孔道的开闭受钙离子的调控 | 在代谢偶联、神经冲动传递、早期胚胎发育和细胞分化过程中具有重要作用，间隙连接是可以随细胞内的变化而进行开关的动态结构 |
| 通讯连接<br>胞间连丝 | 两相邻植物细胞的质膜相连形成管状（20～40nm）结构，内质网从中穿过 | 功能上与动物细胞的间隙连接类似，可调节通透性，某些植物病毒能制造特殊的蛋白质，使胞间连丝的有效孔径扩大，某些细胞蛋白质和核酸能够通过胞间连丝进入另外一个细胞 |
| 化学突触 | 兴奋细胞间的一种连接方式 | 通过释放神经递质来传导神经冲动 |
