### Front
细胞连接有哪几种类型，各有什么功能？

### Back
细胞连接主要分为**封闭连接**、**锚定连接**和**通讯连接**三大类：

| 大类 | 具体类型 | 连接部位/特点 | 主要功能 |
| :--- | :--- | :--- | :--- |
| **封闭连接** | **紧密连接** | 相邻上皮细胞质膜紧密靠拢，无间隙，形成跨膜蛋白咬合线 | ①**形成渗透屏障**：阻止可溶性物质从细胞间隙扩散；<br>②**维持细胞极性**：防止膜蛋白与膜脂侧向扩散。 |
| **锚定连接** | **桥粒** | 相邻细胞间连接，与**中间丝**相连 | 增强细胞抵抗外界压力与张力的机械强度。 |
| | **半桥粒** | 细胞与细胞外基质（基膜）连接，与**中间丝**相连 | 使上皮细胞黏着在基膜上。 |
| | **黏着带** | 相邻细胞间连接，与**微丝（肌动蛋白丝）**相连 | 促使上皮细胞层弯曲，参与胚胎发育中神经管等结构的形成。 |
| | **黏着斑** | 细胞与细胞外基质间连接，与**微丝（肌动蛋白丝）**相连 | 维持细胞运动过程中的张力，传导影响细胞生长的信号。 |
| **通讯连接** | **间隙连接** | 动物细胞间，由连接分子蛋白形成亲水性通道 | 允许小分子物质通过，实现细胞间代谢偶联与电偶联，传递电信号和协调肌肉收缩。 |
| | **胞间连丝** | 植物细胞特有，贯穿细胞壁 | 完成植物细胞间的物质运输和信号传递，协调基因表达与生理功能。 |
| | **化学突触** | 可兴奋细胞之间 | 通过释放神经递质完成神经冲动的传导。 |

### Front
什么是细胞粘着及其分子基础？

### Back
**一、细胞粘着的概念**  
细胞粘着（cell adhesion）是指细胞通过膜上的特定分子与相邻细胞或细胞外基质（ECM）相互识别并紧密结合的过程。

**二、细胞粘着的分子基础**  
细胞粘着的分子基础是**细胞粘着分子（cell adhesion molecule, CAM）**，它们是跨膜整合蛋白，通过胞外区实现细胞间或细胞与基质间的相互作用。

**1. CAM 介导的结合模式**：
* **同亲型结合**：相邻细胞表面相同种类的粘着分子相互识别与结合。
* **异亲型结合**：相邻细胞表面不同种类的粘着分子相互识别与结合。
* **衔接分子依赖性结合**：相邻细胞表面的同种粘着分子借助细胞外衔接分子进行相互结合。

**2. CAM 的四大主要家族比较**：

| 家族名称 | 结合模式 | 阳离子依赖性 | 主要结构与功能特征 |
| :--- | :--- | :--- | :--- |
| **钙黏蛋白 (Cadherin)** | 同亲型结合 | 依赖 \(\text{Ca}^{2+}\) | 介导细胞与细胞间的粘着（如参与黏着带、桥粒），在胚胎发育、组织分化与器官构建中起重要作用。 |
| **选择素 (Selectin)** | 异亲型结合 | 依赖 \(\text{Ca}^{2+}\) | 胞外区含有凝集素（lectin）结构域，识别特异性寡糖链；主要介导白细胞与血管内皮细胞的识别与滚动粘着。 |
| **整联蛋白 (Integrin)** | 异亲型结合为主 | 依赖 \(\text{Ca}^{2+}\) 或 \(\text{Mg}^{2+}\) | 由 \(\alpha\)、\(\beta\) 亚基形成跨膜异二聚体；主要介导细胞与细胞外基质（ECM）的粘着（如黏着斑、半桥粒），并传导“由内向外”和“由外向内”的双向信号。 |
| **免疫球蛋白超家族 (IgSF)** | 同亲型或异亲型 | **不依赖** \(\text{Ca}^{2+}\) | 含有与免疫球蛋白类似结构的结构域；介导淋巴细胞/免疫应答及神经系统发育中的细胞粘着（如 NCAM）。 |

### Front
胶原的合成与装配过程

### Back
胶原的合成与装配是一个跨细胞内和细胞外多步骤协同的过程：

**1. 细胞内的合成与加工修饰**
* **前 \(\alpha\) 链合成**：胶原肽链首先以**前 \(\alpha\) 链**的形式在粗面内质网（rER）膜结合的核糖体上合成。
* **羟基化与糖基化**：前 \(\alpha\) 链进入 rER 腔后信号肽被切除，链上的脯氨酸和赖氨酸残基被羟基化形成羟脯氨酸和羟赖氨酸，部分羟赖氨酸随后被糖基化。
* **三股螺旋（前胶原）形成**：带有前肽的 3 条前 \(\alpha\) 链在内质网腔内装配形成具有 3 股螺旋结构的**前胶原分子**，随后经高尔基体包装并分泌至细胞外。

**2. 细胞外的切断与自我装配**
* **原胶原形成**：分泌到细胞外后，特异性酶切除前胶原分子的末端前肽，转化为**原胶原分子**。
* **胶原原纤维与胶原纤维生成**：原胶原分子以 \(1/4\) 交错平行排列的方式自我装配形成直径 \(10 \sim 30\text{ nm}\) 的**胶原原纤维**，胶原原纤维再进一步聚合形成直径 \(500 \sim 3000\text{ nm}\) 的**胶原纤维**。

**3. 装配影响因素与临床联系**
* **维生素 C 的作用**：脯氨酸和赖氨酸残基的羟基化需要维生素 C（抗坏血酸）参与。若缺乏维生素 C，前 \(\alpha\) 链无法形成稳定的三股螺旋并在细胞内降解，导致坏血病。
* **前肽切除酶的作用**：若缺乏切除前肽的酶，原胶原无法正常装配成高度有序的胶原纤维，会导致皮肤和血管脆弱、皮肤弹性过强等异常。

### Front
胞外基质的主要成分类型与功能总结

### Back
胞外基质（extracellular matrix, ECM）是由细胞分泌到细胞外空间，由蛋白质和多糖构成的复杂网络结构。其主要组成成分类型及功能如下：

| 成分分类 | 主要代表成员 | 结构特点 | 生物学功能 |
| :--- | :--- | :--- | :--- |
| **结构蛋白** | **胶原 (collagen)** | 呈纤维状，由 3 条 \(\alpha\) 链盘绕形成三股螺旋结构（原胶原） | ECM 中含量最高；刚性与抗张力强度最大，构成 ECM 的骨架结构。 |
| | **弹性蛋白 (elastin)** | 高度疏水的非糖基化蛋白，呈无规则卷曲状态并通过残基交联成网状 | 与胶原共存，赋予组织（如皮肤、血管、肺等）弹性和韧性。 |
| **糖胺聚糖与蛋白聚糖** | **糖胺聚糖 (GAG)** | 由重复二糖单位构成的长链多糖，带有大量负电荷（如透明质酸等） | 高度亲水，吸水膨胀形成凝胶，赋予 ECM **抗压**能力、填充空间及润滑作用。 |
| | **蛋白聚糖 (proteoglycan)** | 糖胺聚糖（除透明质酸外）与核心蛋白共价连接形成的大分子 | 赋予软骨抗变形能力；充当生长因子的辅助受体，参与信号转导与调控。 |
| **粘连糖蛋白** | **纤连蛋白 (FN)** | 二聚体高分子糖蛋白，结构域中含有 **RGD** 三肽序列 | 介导细胞与 ECM 粘着，维持细胞形态，促进细胞迁移、血液凝固与创伤修复。 |
| | **层粘连蛋白 (LN)** | 主要分布于基膜，由 \(\alpha, \beta, \gamma\) 三条链连接形成 **“十字”形** | 将上皮细胞锚定在基膜上，在胚胎发育与组织分化中起重要作用。 |

**【特化的胞外基质结构】**
1. **基膜 (basal lamina)**：位于上皮细胞基底面，主要成分为 **IV 型胶原、层粘连蛋白、巢蛋白和基膜蛋白聚糖**，起物理支撑、选择性分子屏障及引导细胞迁移等作用。
2. **细胞外被 (cell coat)**：细胞质膜外表面覆盖的一层粘多糖物质（糖萼），起保护与细胞识别作用。
3. **植物细胞壁**：植物细胞特有的胞外基质，主要成分为**纤维素、半纤维素、果胶和木质素**，提供机械支撑与抗张强度。

### Front
论述题：如何认识细胞的社会性？

### Back
细胞的社会性是指在多细胞有机体中，同种或异种细胞之间通过复杂的相互作用与协同配合，有机地组织在一起，共同完成生命活动、维持组织器官结构与功能的特性。

认识细胞的社会性可从以下几个核心层面进行剖析：

**1. 产生社会联系的基本方式**
细胞主要通过**细胞通讯**、**细胞连接**、**细胞黏着**以及**细胞与细胞外基质（ECM）的相互作用**四种基本方式产生密切的社会联系。

**2. 细胞社会性的结构与分子基础**
* **细胞连接（结构基础）**：是多细胞有机体中相邻细胞间协同作用的重要组织方式（包括封闭连接、锚定连接和通讯连接），赋予组织机械强度并实现屏障与信息交流功能。
* **细胞黏着分子（CAM）**：跨膜整合蛋白（如钙黏蛋白、选择素、整联蛋白和 IgSF）介导细胞间或细胞与基质间的特异性识别与结合，是细胞识别与定向集聚的分子前提。
* **细胞外基质（支架与调控网络）**：由细胞分泌的蛋白和多糖（如胶原、弹性蛋白、糖胺聚糖、纤连蛋白和层粘连蛋白等）构成复杂网络，不仅提供物理支撑与锚定位点，还调控细胞形态、迁移与信号接收。

**3. 细胞社会性的生理意义与体现**
* **构建组织与器官**：细胞通过选择性识别与粘着有序地组织起来，形成执行特定生理功能的组织与器官。
* **协调代谢与生命活动**：通过间隙连接、胞间连丝以及化学突触等通讯连接，实现细胞间的信号传递、代谢偶联与电偶联，确保整体反应的同步与协调。
* **调控发育、分化与稳态**：在胚胎发育、组织再生、免疫应答及创伤修复等过程中，细胞间的相互作用精准调控着细胞的增殖、分化、迁移以及程序性死亡（凋亡）。
